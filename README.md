# Adham Abu Hager — Portfolio

A responsive portfolio for Adham Abu Hager, a Full-Stack Developer based in Amman, Jordan.

## Live site

[my-portfolio-five-azure-69.vercel.app](https://my-portfolio-five-azure-69.vercel.app/)

## What it includes

- Professional introduction and engineering focus
- Verified technical skills across TypeScript/Node.js and .NET
- Detailed case studies for Aoun and UniEvents
- Experience, training, and education timeline
- Downloadable CV and direct contact links
- Responsive layout, accessible navigation, reduced-motion support, and SEO metadata

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Local development

```bash
npm ci
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run lint
npm run build
```
